# Simulador-de-Sistema-Operativo-de-1-n-cleo.-
Simulador de SO, desarrollado en Python estructural, incluye: administrador de memoria (emplea método best-fit y particiones de memoria variable), planificador de CPU (prioriza procesos empleando algoritmo SRTF). Se basa en un diagrama de 5 estados: Nuevo, Listos, Listo/Suspendido, Ejecución, Terminado.
